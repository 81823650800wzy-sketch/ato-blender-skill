# 主题、补充素材与最终色彩

## 先确定视觉方案

为歌曲及其情节段记录情绪、素材形态、字体/笔触、颜色、UI 家族、动画力度和色彩曲线目标。允许同曲随情节换风格，保留一两种识别元素连接全片；避免每次切镜随机换皮。示例是选项，不是所有视频的固定滤镜：

| 主题 | 补充素材和字形 | 色彩与动作方向 |
| --- | --- | --- |
| 欢快日常 / vlog | 可多用纯白手写线条、简洁涂鸦、轻薄图片边缘 | 自然明亮、柔和高光、清晰肤色；轻快揭示与交互 |
| emo / 孤独 | 克制的笔迹、暗色空间、与意象相符的纸纹或照片 | 可降低饱和、偏冷或沉静阴影；慢揭示、长停留、更多留白 |
| 游戏 / 躁动 / 黑色幽默 | 熟悉的系统提示、游戏信息、故障或夸张意象 | 可用强调色和局部对比，短促状态变化；保留关键文字可读 |
| 旅行 / 成就反讽 | 真实地标、照片/地图/导航组件、题材匹配的图片 | 场景自然色与情绪反差配合，避免所有旅行片强加同一暖色 |

生成提示须写明当前主题、配色、笔触/材质、用途、透明背景需求和摄影光向。欢快 vlog 的白手写可作为默认候选，但要检查白天空上的对比。纸张、纹理、人物和意象要属于同一视觉世界；不够匹配就重新选素材或生成，不以“素材已存在”为理由塞入。精确文字独立排字，图像只提供视觉资产。

## 调色流程

1. 检查源片色彩空间、动态范围与显示转换；HDR/Log 若存在须正确转换。确定 Blender 工作空间和输出显示转换，避免重复套转换或用 UI 截图推断相机色彩。
2. 先匹配各实拍片的白平衡、曝光、肤色和黑白点，再匹配合成素材的光向、局部对比和颜色。不同背景仍可保持叙事需要的差异。
3. 在统一颜色管理中调整主曲线和必要的通道曲线，再做饱和、局部强调或颗粒。emo 的阴影与欢快 vlog 的明亮程度分别设计，禁止所有片套同一 LUT/曲线。
4. 检查曲线是否压死暗部、剪断高光、漂移肤色或让控件和歌词丢失对比。纯白手写和真实 UI 不应被整体滤镜染到难读；必要时分层控制，仍保持与场景融合。
5. 主题变化应有歌词/情节理由，决定渐变或在重音上切换。先做镜头匹配，避免无理由色温闪跳。调色不能修复追踪漂移或不正确的遮挡。
6. 从最终编码视频检查关键帧与连续片段，结合波形/直方图（环境可用时）及实际显示结果。记录应用的颜色管理、曲线目标和未解决问题；渲染预览通过不等于编码成片通过。

## 临时卡点色与完成调色

用户要求自然通透及好看的出镜末态时，将逐镜完成调色作为底层，单色/色偏/区域故障作为短时装饰；在出镜前合适的音乐事件恢复完成调色并保留稳定窗口。自然风光的黑点、局部对比和色彩增强不能造成自动曝光闪烁、死黑/剪白或统一假晴天。全局 LUT 与空间局部处理分别交付。具体区域回色、两帧故障与末帧检查见 [CHROMA 调色实作](chroma-montage-study.md)。
