# 有色玻璃聊天 · 原位坠落与破碎

用于需要情绪叙事、手机聊天悬浮框、磨砂有色玻璃、原位下落和玻璃破碎的 vlog 镜头。用户已要求保存此类做法，遇到类似组件先查已有资产和效果配方；复用机制，按新素材重排构图、文字、节奏和边界，不机械复用旧聊天内容或绝对时间。

## 资产与画面所有权

聊天卡保留独立的圆角玻璃、尾部、头像、艺术字形和根控制器；发送方的头像、颜色、方向和行为一致。文字长度决定尺寸及阅读窗口。位图艺术字需要重新生成字形，不能把只改 `text` 元数据说成已经更新文字。

同一 Voronoi 单元按源 UV 同时分割玻璃、文字和头像。每片使用原卡局部坐标与自己的质心偏移，整卡触底后由整卡切换到分片；分片的几何、字形和头像共同运动与淡出，不能留下完整悬空文字或重复头像。

有实拍前景时，保真实拍 RGB，生图只辅助 alpha。沿用用户的出现条件；例如限定手机为主体时才出现聊天，则入场、阅读、坠落、破碎及碎片淡出都纳入手机镜头可见窗口，切回风景前清干净。不要据此给其他叙事强加同一条件。

## 有色玻璃

轻磨砂、低镜面、冷暖适应环境；内容清晰、边缘克制，不能用刺眼反光体现玻璃。发送/接收可分别用蓝、绿着色。区分原生材质预览与屏幕合成，实际检查后再报告折射结果。

已核查例子的原生材质起点：粗糙度0.26、IOR1.22、Transmission0.65、Specular IOR Level0.12、低强度显示着色Emission0.18；与透明着色器按 `appearance × 0.58` 混合。sRGB蓝色(80,148,184)、绿色(80,184,159)先转线性。圆角约20px，轻倒角约2.5px。数值随画幅、光线、背景和投影尺寸调整，不是通用物理测量。

该例成片使用屏幕空间玻璃近似：局部背景Gaussian sigma2.4px，透过图像55%与着色45%混合，再以玻璃mask×0.78合成，边缘轻提亮。原生Principled预览与此近似不保证逐像素一致。旧配置的 `glass_opacity=0.52` 没有被该版合成器读取，不能将其误记录为实际透明度；保存生效的节点/代码参数。

## 原位释放、触底与破碎

1. 按主体和留白落位，轻弹入场后留阅读时间，不为坠落预先分散重排。示例入场0.25s、尺度0.88→1并小幅超调，最短阅读停留1.1s；新文案按阅读量重算。
2. 按实际画幅建立屏幕四边碰撞容器。屏幕UI可约束为XY平面内平移与Z轴转动；不允许向相机或背景逃逸。无实景参照时以画幅视觉中心为相机基准，不意味着把卡片放正中央。
3. 正常时间尺度求解整卡，检测真实下边界接触。目标拍点仅用于估算释放帧，重新求解并按真实接触对声音；阅读和物理冲突时改安排，不把重力动画强行加速。
4. 接触后切换到分片，原生刚体继续处理分离、转动、回弹和屏幕边界碰撞。保存源求解场景，另保存每帧变换供可移植合成。独立求解的不同波次不能声称已经发生彼此碰撞。
5. 碎片在窗口内渐隐；示例寿命0.30–0.48s，前55%保持、后45%按三次曲线淡出。新节奏需保留足够辨认破碎的时间，不以整卡直接透明消失替代破碎。

示例单位为100px/Blender单位、1920×1080、30fps；重力(0,-9.81,0)、substeps16、solver80、time_scale1。整卡BOX代理：摩擦0.6、恢复0.25、linear damping0.035、angular damping0.08、margin0.002；碎片凸包：mass0.10、摩擦0.55、恢复0.30、linear damping0.11、angular damping0.08、margin0.001。12片Voronoi，确定性seed，分片初速度X约±3.8、Y向上1.2–2.5单位/s，属于艺术化破碎冲量，不是材料断裂测量。

### 已验证的释放陷阱

碎片的运动学准备关键帧若默认Bezier且在释放前一帧结束，末端速度会降为零，结果看似已分片却几乎不散开。示例用线性位置轨迹在破碎帧f的f-3、f-2、f-1准备运动，并将轨迹延续到f+3，在f切换为动态，顺序求解缓存；随后检查实际缓存的位移/速度，而不是只看写入的初速度参数。

EEVEE复杂场景中仅把透明度设为零可能留下透明排序/反射负担。整卡、碎片及其他不在可见窗口的网格同时用可见性关键帧关闭；整卡关闭与碎片打开在同一破碎帧完成。根对象的隐藏不一定隐藏所有子网格，需核对实际子对象。

## 声音、验证和保存

整卡落地使用玻璃接触声，破碎才配玻璃破碎声。把接触、破碎、弹入分为不同事件，裁切源起音，对齐实际帧，按位置和力度调整音量、声像和尾响。示例破碎声高通1700Hz削弱锤击低频，效果总线150%；这些是本例混音起点，其他作品按音乐和响度重配，不将150%当所有项目的默认值。

检查入场、阅读、释放、接触、破碎后连续帧、最终消失和切回风景。验证边界、UV字形、头像身份、无重影/频闪、碎片确实散开、源声音起音及编码同步。不要用一张破碎静帧或解码通过代替完整视觉/听觉判断。

在资产库登记静态Collection、带关键帧的动作参考、材质/物理/合成配方、短预览、声音来源、原生求解文件、烘焙缓存及已完成的验证。动作参考可用于识别风格；改变布局、画幅、文案尺寸或对象数量时重新求解，不平移旧的落地缓存绕过屏幕边界。个人工程与绝对路径留在本地资产索引，skill仅存通用做法。
