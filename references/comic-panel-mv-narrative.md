# 漫画格MV叙事

分类名：**漫画格mv叙事**。用于音乐驱动的漫画页面、弹性不规则格子、风格文字与主体互动，以及分格和完整画面的交替。它是以页面和镜头关系推进的MV叙事，不等于每个鼓点都挤入一个格子，也不要求有对白或线性故事。

## 案例定位与认可范围

2026-10-19，用户明确要求以 Peach 的 V6 全漫画版本为基底，只适度改变循环的入场顺序、同屏内容和单独展示，随后要求把设计归入此类别。V11落实编排，用户指出部分完整画面切镜异常；V12修复进出连续性。**用户选定的是V6的漫画格与风格文字方向；归档不等于所有早期版本或V12全片获得最终审美认可。**

历史工程标识：`peach_geometry_mv_v6`、`peach_geometry_mv_v11`、`peach_geometry_mv_v12`。以下入口相对各工程根目录；工程仅作本机查阅，不是技能的运行依赖，不随技能复制歌曲、歌词全文、私人素材、系统字体或整套影片。

| 入口 | 可迁移机制 |
|---|---|
| `scripts/comic_layout.py` | 鼓点候选、弹性边界、四边形内缩、私有格内区域、动态主字 |
| `scripts/comic_maximal.py` | 多字体底片、轮廓字、局部翻卡、推页/翻页 |
| `scripts/peach_comic.py` | 不同材质的独立格内设计、主体环绕、文字互动、整体包络适配 |
| `scripts/comic_revision_v11.py` | `CASTS`、`ENTRY_FLIPS`、`SOLO_WINDOWS`，循环顺序与少量整格展示 |
| `scripts/continuous_cards_v12.py` | 同一卡片连续放大、归位及跨页承接 |
| `reviews/transition_checks.json`、`transition_encoded_entry.jpg`、`transition_encoded_return.jpg` | 进出端点与实际编码连续帧证据 |

本例为1080×1920、30fps、约31.47秒，四种桃子材质；六段单独展示含进出约占18%。这些是案例值，不是新任务的版式、时长、材质数或分格比例要求。

## 先建立页面叙事

为每个乐句登记主格职责、配格内容、入场先后、页面交接与是否需要完整画面。主格承载当前歌词或核心动作，配格补充材质、剖面、局部细节、反应或另一时刻，避免几格只播放相同内容的缩小副本。

- 保留用户选中的风格基底。要求“在V6上适当修改”时，直接继承其格内排版、材料与运动，只改所需编排；不要借修订把丰富漫画重设计成简洁海报或另一套全屏极繁系统。
- 循环变化同时考虑**入场方向、主体顺序、画面拓扑、主配格职责**，不只改随机种子或颜色。对应循环可反向入格、交换主配格、更换剖面与全貌；保留适量可识别母题。
- 同屏内容要有意义的差异。可用同一主题的软、硬、薄膜、切面等形态，或不同叙事视点；形态、明暗、底色、字体、粒子结构共同区分，不靠换标签冒充新内容。
- 在乐句重心或材质动作处插入少量整格展示，让观众辨认主体、材料与关键词。不能因添加单独展示就清空所有视觉层次，也不必让每个大拍都承担分格扩张。

## 弹性格子与内容所有权

用同一外四边形和共享分割顶点生成邻格，使挤压、回弹时边界共同移动；不要独立动画相邻格的边，避免缝隙和互相穿过。先构造不重叠分区，再按边法线内缩成沟槽，最后绘制边框。

可用阻尼阶跃产生Q弹：

`E(t) = 1 − exp(−d·t) · [cos(w·t) + (d/w)·sin(w·t)]`，`t≤0`取0。

超调幅度由最小格尺寸、主体可读性和阅读时长限制，不为Q弹允许格子反转。V6例子先分出宽行，再分宽行内部，避免第一步就生成长窄轨道；新画幅仍按实际内容选择切分。

整体左右/上下反射可改变入场方向而保留共享边界；反射后重新排序四角，保持内容朝向正确，不能让画面贴图跟着镜像或倒立。拓扑、材质列表和cue索引需同步，不要只重排一张表。

每格有自己的主体区、主字带和装饰区。把包含果柄、叶片、针尖及必要效果的整体包络裁好，再按宽高适配；环绕字和粒子在格内裁切。主字带与实体主体留出间距。判断稳定格子的高宽比及实际内容，不把刚开始挤入的暂时薄片当作终态。

## 风格文字：大字、差异与物性

格内丰富排印由三层组织：当前主字、材料/叙事说明、低权重环境字片。环境字不能与当前主字同权重地重复堆叠。若用户选择无小字幕，则由大字的展示和歌词时间表保证内容，不用底部小字幕补漏。

| 字体/运动职责 | 适合表达与实现 |
|---|---|
| 粗黑/凝练大字 | 重音、落位和体感；带短侧壁的挤出，不让彩色偏移变成多份竞争主字 |
| 衬线/斜体 | 柔软、流动、对角张力；与窄体和黑体建立笔画与速度反差 |
| 窄体/字内条纹 | 纵深、折射和速度；条纹受字形alpha限制，不能覆盖整个主体 |
| 逐字落下/多米诺铰链 | 字级错拍、回弹与物性；留完整词的辨认窗口 |
| 摆锤倾转/弹性压缩 | 入场后仍有惯性；与主体共享接触时刻但不共用全部振幅 |
| 局部切片/错版/描边脉冲 | 小鼓点细节，短而局部，不复制全画面抖动 |

大透视用实际投影或平面变换建立近大远小，再按画面边界适配；不能把透视字塞进过小固定框后宣称保留张力。每个主词有合适的位置、阅读尺度和退出关系，循环时改变位置与行进方向。

文字可压住软体、受硬质接触反冲、沿不规则轮廓环绕、在膜面接触点触发内陷/戳破。沿椭圆或语义轮廓排字时，字向随局部切线变化；前后层级明确。背景字按完整实体轮廓遮挡，前景字保持整张字面层级；不要用局部盖顶造成文字在实体内任意切换前后。

**歌词与装饰标签分开。** 替换材料面板底部的重复主题字时，仅作用于装饰角色/区域，不做全局字符串替换；本例曾发现装饰PEACH→PRISM会误改主歌词，已用角色/位置约束并检查实际主字。标签、短拟声词是否保留由当前风格决定，不规定所有项目都用或都去除。

## 完整画面与格子：同一卡片连续交接

本次主要反例：V11切入另一张独立全屏画面，结束后直接切回后台继续更新的漫画。主体会骤缩、边框回跳，旁格可能已经挤到一半；在页末先缩回再换页还会产生无意义的二次运动。

修正时保持**卡片身份、源时间和绘制所有权**一致：

1. 从当前实际主格取得内缩后的四角 `Q(t)`，以缓动量 `p` 插值到满屏四角：`Qsolo=(1−p)·Q(t)+p·Qfull`。图、字和效果共同随这张卡片变化。
2. 同一时刻只绘制一个主卡片；放大期间可前置遮住配格，不在底下保留另一份原主体。使用当前时间的材料与相机姿态，不改用另一帧/另一相位。
3. 边框随 `1−p` 退出。`p=1`时直接使用完整卡片像素，保证无旧边框、沟槽、旧面板残影或终态缩放差异。
4. 在同一页中途退出，连续返回当前合法主格，再恢复一般分格渲染。应避免在邻格的挤入峰值中途突然露出后台状态；可重排cue、延后返回，或选择边界已稳定的窗口。
5. 若展示结束就是下一页，保持满屏至页交接，直接成为出页画面；不要先缩回旧格再推页/翻页。页交接与卡片缩放只有一个主导动作，不同时叠加两个独立转场。

V12例子入场约0.13秒、中途归位0.20秒；新任务按拍长、位移、主体辨认与动作幅度决定。是否有意硬切也由叙事决定，不能把所有完整镜头强制做成缩放。

## 节奏和声音

大鼓点驱动页面重构、主体Q弹、硬质反冲、深度进出、触碰/破膜等主事件；小鼓点驱动字边错版、局部切片、描边、粒子闪烁及轻短声。两者都跟音乐，但不要每个小拍也拉伸整个主体或晃动相机。

声音按可见动作安排预备、接触、体感和尾音，并依材料变化。隐藏在完整画面后方的格子入场不应继续播放显著落位声；重排材质顺序后同步重新检查触碰声和破膜声。当前案例V12沿用V6七类程序拟音、80个cue，非全类别通用配额；分频候选/30fps量化及相关性不能替代主观听音。

## 审核与交付

- **逐帧布局**：共享分区面积、格间内区无重叠、沟槽、角点顺序；终态格比例与真实文字/主体适配。反射后的共线边可能触发float32凸多边形相交误判，必要时用float64裁剪并核对可见画面，不放宽真正重叠的阈值。
- **逐词阅读**：入场、最拥挤、完整词保持、退出；主字不被装饰标签替换，字级序列不能只显示首几个字母。完整歌词按当前文本政策核对，不用关键词数冒充覆盖。
- **完整画面端点**：进入起点匹配当前格；满屏终态匹配完整卡片；中途归位终态匹配当前分格；跨页段末仍为完整画面。检查actor只画一次、框线退出和源时间连续。
- **连续动作**：对每次完整画面进出及循环变化，从实际编码视频抽相邻帧或播放连续短段，重点看骤缩、构图回跳、格子半入场、旧边框残影与双重转场。不能只看间隔数秒的海报接触表。
- **艺术与技术分开**：检查同屏内容差异、主次、密度起伏和循环变化；再做全帧解码、边界/编码接缝源帧对照、音轨连续性和工程解压复现。没做听音或最终用户确认就如实记录，不由技术通过推导审美认可。

原生三维主体环绕、2D/2.5D卡片/文字合成、参数Q弹与真实物理求解分别说明。新任务可用Blender或二维合成实现同样关系，不必复制本例的全部代码、数值或素材。摄影贴图、棋盘格、小字幕在本片被否定；作为本案例约束保留，不能扩张为所有漫画格MV的永久禁用规则。
