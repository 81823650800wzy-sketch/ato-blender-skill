# 声音剪辑与音画因果

声音先决定观看的连续性，再为选定事件增加强调。用户歌曲保留原速原调；不要因为风格推断而替换歌曲。没有独立听觉通道时，波形、频谱、ASR和视频动作只能提供候选，不得宣称听见了特定音效或所有切点精准卡拍。

## 从混合参考能确认什么

先提取音轨，定位对白/音乐/静段的可能边界，结合原视频字幕与段落。能量突变不等于鼓点；高频突变可能是辅音、镲、摩擦、压缩失真或音效。单一混合音轨不能可靠证明某种声响是现场收音还是后配。记录 `observed / estimated / proposed`；不要用“参考用了whoosh”的猜测给每镜加whoosh。

用户提供的七条参考中，R7画面字幕与本地识别支持“前段对白铺垫”的判断，但ASR的名字/语句仍有错误。R1–R6歌声识别质量不一，R4/R6尤其不足；本轮未逐声听辨SFX。下面是制作策略，不冒称原片原样音效清单。

## 分轨与职责

保留 `dialogue / music / ambience / foley / designed_fx` 的适用分轨。vlog环境声能建立地点，叙事对白保持清楚，混剪以歌曲组织节奏，海报变形可有克制的设计声。并非每片都需五轨；没有作用的轨道可省。

| 事件 | 声音设计选择 | 时间关系 |
|---|---|---|
| 下一空间/人物预告 | 下一镜环境或对白提前进入（J-cut） | 先产生期待，再显示来源，不提前泄露反转 |
| 反应镜头/换景 | 上一句话/尾音持续到新画面（L-cut），环境交叉淡化 | 保护句意和情绪，不逐切点把底噪切断 |
| 实体接触/落位/关门 | 与材质相符的短接触声；需要重量时再叠低频 | 瞬态对齐接触/落位帧，尾声跟随环境 |
| 撕纸/页面展开 | 纸张摩擦、短裂声或安静的运动 | 起音跟随撕开、落位可单独强调，避免纸片一动就轰鸣 |
| UI点按/状态变化 | 内容相关的短点击/提示 | 在状态发生时触发，不覆盖重要人声辅音 |
| 快速方向运动 | 适量空气移动/反向预吸/声像移动 | 预备→速度峰值→短尾；无视向关联就不用 |
| 情绪转折/高潮出口 | 减少配器/音效、环境显露或留停顿 | 静默与减法也是设计，歌曲不中断时也可仅撤掉附加音效 |

以上是可选，不把同一套“上升→轰→呼啸”循环贴在每个切点。音乐已经有足够冲击时，先尝试不加音效；加声后应使事件更明确而非只有更响。

## 混音与核对

1. 保持源对白的前后字和呼吸，不让转场截掉音节。若剪短对白改变原意，重选片段；不同空间底噪用合适声桥承接。
2. 配乐避让对白可先自动化音量，必要时有限动态EQ/侧链；目标以清晰且不抽吸为准，不通用套固定duck dB。音效的低频/高频按叙事层级减法，避免持续糊低频和刺耳堆叠。
3. J/L音频事件可跨视频切点，单独记录源入点、输出开始/结束、增益、淡化与所属事件。不要强迫所有声音裁在视频整数帧；接触落点才与帧格对照。
4. 检查削波、整体响度与真峰值，最终平台目标按请求选择，不一律最大化响度。淡化防止截断点击；重叠时验证总线而非只看单轨峰值。低码率参考不是声音母版。
5. 有听觉条件时分别听音轨、看无声画面、看完整音画段落：判断声音是否有来源、是否掩盖对白、是否同质重复、密集后是否有松弛。无听检条件时给出可调整分轨与cue表，并如实标注待听检，继续可验证工作。

生成或采购素材按现有工具和授权范围执行。普通点击可程序生成；纸纤维、真实环境与拟音优先合适的可用录音。参考音轨只用于本地分析，不从中抽取音乐/音效默认加入新成片。
