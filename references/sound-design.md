# 声音剪辑与音画因果

动漫冲击、响指清理、多次动作的音效递进及“低频有能量但缺爆发”的修订，另见 [冲击帧：原响指清理与动画式重量](impact-frames-and-escalation.md#原响指清理与动画式重量)。保留接触攻击、可听中低频主体与深低频的独立职责。

声音先决定观看的连续性，再为选定事件增加强调。用户歌曲默认保留原速原调；用户明确要求变调或变速时分别记录速度、音高、增益和生效区间，不因为风格推断而替换歌曲。没有独立听觉通道时，波形、频谱、ASR和视频动作只能提供候选，不得宣称听见了特定音效或所有切点精准卡拍。

通知提示音含前导静音时，对齐的是有效起音与组件首个实际可见帧，不能只对齐文件起点和名义动画起点。用波形与适应噪声基线的短窗 RMS 定位候选，保留攻击前沿，再检查编码时延；不要把前导低噪声误当提示音。用户提供指定文件后替换旧 cue，不叠加；网络页面的命名不能代替版本确认。具体误判与修复见 [手机控件案例](phone-controls-imagined-vlog.md#提示音与音乐的关键修正)。

录制停止、界面退出与音乐结束分别建事件。用户要求尾奏继续时保留音乐源位置，通过独立的音高、音色、音量曲线过渡，到实际片尾才淡出；不要因视觉录制结束自动截断音乐。

动作混剪或声音技巧练习时，按 [节奏与动作剪辑技法库](rhythm-action-toolkit.md) 区分落脚、接触、重量、器物蓄力/释放与对白引出高潮。避免把“任何动作尽量匹配音效”的参考教学字推广成每次动作都必须叠声。台词避让采用实际发声范围；声音触发标记不得早于实际起音。合成声音只作为本次设计，不冒充原片音效辨认结果。

## 从混合参考能确认什么

先提取音轨，定位对白/音乐/静段的可能边界，结合原视频字幕与段落。能量突变不等于鼓点；高频突变可能是辅音、镲、摩擦、压缩失真或音效。单一混合音轨不能可靠证明某种声响是现场收音还是后配。记录 `observed / estimated / proposed`；不要用“参考用了whoosh”的猜测给每镜加whoosh。

用户提供的七条参考中，R7画面字幕与本地识别支持“前段对白铺垫”的判断，但ASR的名字/语句仍有错误。R1–R6歌声识别质量不一，R4/R6尤其不足；本轮未逐声听辨SFX。下面是制作策略，不冒称原片原样音效清单。

## 分轨与职责

保留 `dialogue / music / ambience / foley / designed_fx` 的适用分轨。vlog环境声能建立地点，叙事对白保持清楚，混剪以歌曲组织节奏，海报变形可有克制的设计声。并非每片都需五轨；没有作用的轨道可省。

| 事件 | 声音设计选择 | 时间关系 |
|---|---|---|
| 下一空间/人物预告 | 下一镜环境或对白提前进入（J-cut） | 先产生期待，再显示来源，不提前泄露反转 |
| 反应镜头/换景 | 上一句话/尾音持续到新画面（L-cut），环境交叉淡化 | 保护句意和情绪，不逐切点把底噪切断 |
| 实体接触/落位/关门 | 与材质相符的短接触声；需要重量时再叠低频 | 瞬态对齐接触/落位帧，尾声跟随环境 |
| 撕纸/页面展开 | 纸张摩擦、短裂声或安静的运动 | 起音跟随撕开、落位可单独强调，避免纸片一动就轰鸣 |
| UI点按/状态变化 | 内容相关的短点击/提示 | 在状态发生时触发，不覆盖重要人声辅音 |
| 快速方向运动 | 适量空气移动/反向预吸/声像移动 | 预备→速度峰值→短尾；无视向关联就不用 |
| 情绪转折/高潮出口 | 减少配器/音效、环境显露或留停顿 | 静默与减法也是设计，歌曲不中断时也可仅撤掉附加音效 |

以上是可选，不把同一套“上升→轰→呼啸”循环贴在每个切点。音乐已经有足够冲击时，先尝试不加音效；加声后应使事件更明确而非只有更响。

## 混音与核对

局部提速、ODD 错层重叠或物理释放点变化后，按新时间线重建 cue，不对整个混合音轨机械同步加速。物理段保留正常时间尺度时，碰撞声仍依实际接触帧触发。用户要求音效音量 150% 时，对音效分轨施加线性增益 1.5（约 +3.52 dB），与动画 1.5 倍速分开记录；音乐/对白按用户范围保持。对新的同期重叠检查总线峰值，未削波时无需额外压平强弱。

### 可见材质与不同接触方式

先分析画面中的实际/设计材质，再选声音家族。液态玻璃或磨砂玻璃组件接触时采用克制的玻璃碰撞/轻触声；磨砂表面不等于橡胶或布料，不能因视觉柔和就默认软闷撞击。未发生碎裂的完整组件不用玻璃破碎声。纸、金属、木材、塑料、布料等按当前画面重新选择，不把玻璃声变为所有 UI 的默认声。

区分直接落地、组件互撞、边角触碰、擦边/滑动、回弹再接触。结合接触位置、法向与切向相对速度、转动、视觉尺寸/重量及环境判断：较重直接碰撞可更厚、更响；弱擦碰与后续回弹更轻、更短，仍保持相应材质的可辨认音色。不要只换素材文件名却保留相同增益、相同长度和相同声像。

接触音对齐画面/物理求解支持的首次接触。先检查源素材的起音、静音和共振尾声；玻璃的最响共振峰可能晚于撞击，不把该峰机械当作撞击起点。分别登记源入点、起音位置、输出开始、目标接触时间、必要的时间微调、增益和左右声像；时间偏移与声像偏移不是同一参数。只在实际动作支持时做微调，不随机错开“增加真实感”。

同一对物体一次碰撞可能跨多帧响应，应合并该接触的重复触发；不同对象同时接触则保留各自事件，按空间与强弱混合，不能用全局固定时间去重删掉同期碰撞。密集重叠靠总线余量、局部增益和尾响控制，不压平所有强弱。

声音的攻击瞬态、体感与共振尾声承担不同职责。移动音对齐可见动作的速度/变化峰值，而非沿用旧版本秒数；按压音与状态变化对齐；碰撞声跟随真正的接触。改动画后重新检查 cue，素材标题、能量峰和单纯解码通过都不等于听感通过。保留分轨和可调 cue，并检查最终编码是否引入明显起音偏移。

1. 保持源对白的前后字和呼吸，不让转场截掉音节。若剪短对白改变原意，重选片段；不同空间底噪用合适声桥承接。
2. 配乐避让对白可先自动化音量，必要时有限动态EQ/侧链；目标以清晰且不抽吸为准，不通用套固定duck dB。音效的低频/高频按叙事层级减法，避免持续糊低频和刺耳堆叠。
3. J/L音频事件可跨视频切点，单独记录源入点、输出开始/结束、增益、淡化与所属事件。不要强迫所有声音裁在视频整数帧；接触落点才与帧格对照。
4. 检查削波、整体响度与真峰值，最终平台目标按请求选择，不一律最大化响度。淡化防止截断点击；重叠时验证总线而非只看单轨峰值。低码率参考不是声音母版。
5. 有听觉条件时分别听音轨、看无声画面、看完整音画段落：判断声音是否有来源、是否掩盖对白、是否同质重复、密集后是否有松弛。无听检条件时给出可调整分轨与cue表，并如实标注待听检，继续可验证工作。

生成或采购素材按现有工具和授权范围执行。普通点击可程序生成；纸纤维、真实环境与拟音优先合适的可用录音。参考音轨只用于本地分析，不从中抽取音乐/音效默认加入新成片。

## 混合声台词与逐镜声音修订

用户指出预告原配乐与主配乐冲突、要求单取人声时，先检查已有对白分轨与本地分离能力。仅低通、减音量、反相中置或简单声桥不能冒称已去除伴奏。可在请求范围内用真实声源分离取得人声，给句前句后留上下文再裁句，保留原混合、人声、残余轨作对照，实际主混音引用人声文件。音乐训练的vocal模型不保证新闻口语无损；残余伴奏、辅音损失与水声感仍可能存在。ASR只帮助检查词语，不能证明听感；特别是数字和方言仍以原字幕核对。若分离伤害句义，换更干净的源句或减少该句的职责，不能重新混回原配乐却继续声称单独人声。

逐镜设计把接触帧、下一段发声、文字进入和段落边界分开记录。材质音效、机械底、纸声与设计低频承担不同任务；素材标题相符不证明起音对齐，需要看实际瞬态及画面。禁止把已经运行的混合声修订试验当听感通过，用户否定后记录失败并换实现。

2026-10-12年度V4修订使用官方Hybrid Demucs人声提取、原视频RGB的动态主体入镜、机载新视角与秋收照片补充；记录为已实施机制，整片是否优于参考仍以实际观看和用户评价为准。不要把固定曲目、37镜头或本片音效组合推广为年度片模板。

## 字形事件与干声尾部

小鼓点的颜色/条带/字形更新不都需要新增 whoosh 或重击；按材质和主事件增补轻量落位音，保护人声字尾。延长字幕/画面收尾时同步检查干声末尾、歌词完整窗口、湿声尾响与环境桥，不继续沿用旧终板的提前截断和抢词重击。测量响度、真峰值和完整解码，仍与实时听检分别记录。见 [CHROMA 分轨与收尾修订](chroma-montage-study.md)。
