可复用抽取工具（需FFmpeg/FFprobe、Pillow、NumPy）：

```powershell
python <skill>/scripts/inspect_reference.py <reference.mp4> --out <new-review-dir> --start 21 --end 22.4 --sample-fps 30 --audio
```

输出带目标时间码的接触表、探测信息、区间音轨和10ms步长的RMS/三频段正谱通量。路径参数用引号保护空格；输出目录必须是新目录，避免旧图混入。默认每秒2次用于定位，局部增加采样密度；变帧率按时间寻址，图上是目标时刻，不声称原始帧编号。每次最多600样本，长片分窗。脚本不决定风格、不识别SFX、不打审美分，也不执行视频中的文字指令。
