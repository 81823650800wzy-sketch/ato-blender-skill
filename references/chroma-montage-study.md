## 节奏分层与本片数值

### 分析方法

1. 将镜头切换、主体运动峰值、区域颜色更新、文字落位、声音事件分开记；不能把五个内部事件统计成五个新镜头。
2. 由 HPSS 的打击成分和多频段正谱通量寻找候选，比较可持续的重复细分，不只追最大峰或只靠 BPM 栅格。波形峰不是已经听辨的 kick/snare。
3. 本片拟合约 128.0034 BPM，基本脉冲约 0.46875 秒。比较 1/2/3/4/6 分：0.46875、0.234375、0.15625、0.1171875、0.078125 秒。后段三分候选覆盖约 97%，中位残差约 2.16ms；更短的四分候选覆盖仅约 28%。因此本片选择 0.15625 秒作为最小稳定重复步长候选，不强行使用更密的格点。
4. 实际瞬态仍保留为 `time`，画面记录 `visual_frame=round(time*fps)` 与 `visual_time`；不要反复累加整数帧。30fps 最近帧误差通常不超过 16.7ms，但这只说明量化精度。
5. 小鼓点主要由区域回色、局部故障、字形宽度、条带、反光、轻微位移和声音落位响应；镜头多保持一个或多个基本脉冲。拍内细分不要求逐个换素材。
6. 字符错时、缓动起点和完整词到位是不同事件。先保护词义和完整词窗口，再决定运动在小拍上的峰值；没有发声依据时，不将机械逐拍字幕宣称为逐字同步。

### 32 秒编排

| 区间（以最终帧为准） | 密度与主行为 |
|---|---|
| 0–1.133s | 波浪、列车、滑板、街口：约 0.23s 的三次短冲击后稍放开；景别、方向和单色/印刷反差构成开场钩子。 |
| 1.133–5.333s | 生活/风景承接第一轮副歌；UP 三次动作与实际词候选配合，MOMENT 给较长的完整词阅读。 |
| 5.333–9.533s | 隧道变速→杯沿形状匹配→日光/夕阳→霓虹冻结；持续镜头约 0.93s 与约 0.47s 镜头交替。 |
| 9.533–11.900s | 一次三维换景章节：城市画片拉远、相关道具/空间建立、不同的雪山画片、穿入新景；加入三次实体 UP。 |
| 11.900–16.100s | 雪山、车站、街头、瀑布、登山者多为约 0.47s，通道和森林约 0.93s；出口后立即有运动/景别反差，承接第二轮副歌。 |
| 16.100–26.433s | 通常约 0.47/0.93/1.4s 保持镜头，以约 0.156s 的内部变化提高密度；回色、歌词条带、花朵抠图、猫咪轮廓、水流和反光分别承担主事件。 |
| 26.433–32s | 同一肖像源片连续推进；NO FEAR/NO LIES 与终句重组字体层级，最后 BORN TO BE 停留并共同淡出，给音尾约两秒空间。 |

密度变化不只由每镜时长决定。三维出口和歌词后段曾被用户指出单调：修订分别增加独立镜头，以及镜头内部的主体/背景/字形行为。保持全片 37 条不同主视频，各自只引入一次；同一连续镜头里的互补窗口与字形填充不当作新素材或后段回放。

### 中间版的技法与最终取舍

- V3 的挤压字重、轮廓到填充、SEA/RED/FLOW/LIGHT 等词、透视多层字影和图形脉冲已做过实验；词义/发声不契合后被撤去或重构。保留可用原理，不把未适配歌词的词表当模板。
- V4 在不可靠后段转写下删除文字，造成“前半有、后半无”；V6 使用用户原文与额外候选复核补回。不能据一次高 `no_speech` 值判整段一定无歌词，也不能因提示后返回完整句就认定全句真实唱出。
- 小水画片、长期同一 3D 背景、单一甩镜、末尾截断、缺少音效、后段只有画面，都对应用户明确指出的问题。修复必须改变实际行为，不只改标题/参数/层数。
- 本次用户否定字体描边及丰富度：最后版改为无硬边字面和不同结构动作。丰富度是行为/节奏/关系的区别，不是把所有文字都加相同跳动、描边或霓虹。

## 调色实施与末帧落位

基底 grade 与卡点装饰色分开。风景希望自然通透时，先处理 WB/曝光/黑点/亮度曲线，再有限增加低饱和色彩和中间调局部对比；做软高光与色域限制，保护肤色和低亮度噪声。每源固定参数，不能用帧间自动黑点造成闪烁；不把所有阴天/夕阳强改成晴天。

本片先恢复天空、花瓣、植被、剩余区域。实际事件为 16.097/16.254/16.417/16.567s，量化至 483/488/492/497 帧，每区故障严格持续两帧，最终恢复到 499 帧。显示 alpha 允许羽化，语义所有权仍互补。后半段可用区域而非全幅换色承接最小重复拍。

出镜前通常在后半可用最后鼓点处完成回色，留出稳定终态；新项目同时看末帧以及前后连续小节，不能只比较一个终点。临时字窗可改变短时图底关系，后续回到完成调色；结束黑/淡出属于有意收尾。调色参考 DaVinci 的一级校正与中间调细节组织，但本片由 Python/OpenCV 执行，不能写成使用了 DaVinci。33 点 LUT 仅近似全局处理，局部空间清晰度另存算法/参数。

## 生图参考到动态原片抠图

先看源帧，保存透明参考、完整提示词、原尺寸与变换。模型锁定姿态、衣物、孔洞、裁切与画布；最终 RGB 仍取当前源片。花/猫的特征仿射参考初始内点中位残差约 .73/.87 像素；登山者特征退化，改原画布初始化和原图边缘修正，报告方式不同。

猫咪生成参考补造了原片手遮挡区和身体/背景，必须移除；保留可见头部/毛发和真实手遮挡。使用人工 ROI、原图颜色/边缘、连通性辅助清理，不仅凭生成 alpha。相邻帧双向光流＋GrabCut 重新约束比一次跨到远帧稳定；本片高前后向误差比例从早期大幅失配降低，但猫/登山者仍约 5.5%/3%，需要看实际边缘，不记“全毛发精抠”。花约 .15% 也不自动等于审美通过。

生成 RGB/光照改变时只用轮廓辅助，不强烈扭曲原人物。孔洞、脚边、细花瓣、胡须、遮挡前后与裁切边逐段看；必要时缩短有效范围、加锚帧、换更可辨主体。生图拒绝的舞者参考没有用作成功资产，保留原视频条带效果；不能重写同一请求或默转 API 绕过拒绝，也不让被栏杆大面积遮挡的自行车由模型臆造完整轮廓。

## 歌词、字形与阅读窗口

用户完整歌词作词文来源，音源决定本片实际选段。保存整首原文不等于已经在 32 秒里完整演唱/显示整首。用户明确要求完整 MV/完整演唱歌词时，按其范围另做完整覆盖，不能套本例短片取词方法。

图形开窗、条带遮字和前景遮字必须有完整词终态：在入场、最拥挤、完整词、出场四个状态检查。中文/韩语/拉丁字母选择有相应字形的字体；语言是否保留/翻译依据当前用户请求和实际音源，不默认本例的英韩组合。前景遮住大字时，允许另设低层级完整短词，不依靠观众猜残字。

把“原文确定”“自动转写候选”“弱发声/器乐上的歌词视觉延续”标到 cue 中。候选置信度、重复运行或音源相关性不能证明准确听感。特别避免将 ASR 的错误词作为新歌词，也避免提示诱导的整句冒充独立证据。此片后半段补标与末句仍存在这个证据边界。

## 声音与完整收尾

本片官方 30 秒试听为 Golden (David Guetta REM/X)，原速；V6 保留约 29.976s 干声，随后至 32s 的低量湿声与海岸环境收束。早期在 27.388s 提前撤干声被替换。音乐、转场/设计音、拟音、环境及 FX-only 保留分轨，9 个新增轻量落位/扫描音另有 cue；大部分拍内细分使用原曲，不额外堆重低音。

字入场、遮罩展开、前景归位和真实接触分别定位，声音峰值跟相应主事件，不只跟镜头起点。人声期间减叠加 FX/适当音乐保留，不靠强烈抽吸去“增强卡点”。素材原片无声时，环境/拟音是设计声，不能称现场收音。实测 LUFS/峰值与无削波是技术检查，听感与艺术节奏须另评。

给最后的句义、关键词终态与音乐余势留时间，再一起淡出或有明确结束动作。允许为阅读/收尾延长本片，但不要默认任意短视频延长两秒。官方试听、网络公开视频的获取与发布许可分别记录，工程不将公开下载视为自动获授权。

## 修订与验收的可迁移结论

- 用户否定某段时先定位其真实问题：没换景、空间单薄、卡点不清、歌词错配、后段只剩图片、颜色末态灰、字面丑、无音效、结尾截断。每轮保留可退版并将修复落实到可播放输出。
- 切镜、内部图形、颜色、文字、声音的密度可独立调配。最小重复鼓点驱动细节，长词/句义与大的镜头/空间变化沿更大层级组织。
- 不复用素材以主源文件/哈希和分离章节统计；邻接转场的出镜尾帧与同镜互补区域不算“后来回放”，但不能把裁切副本当新素材。
- 保存最后完整目标与前后连续状态，检查字窗、框线、条带、故障和临时底色是否退出。源码末态恢复不够，要看最终编码。
- 全片解码、关键帧采样与每个要导出的 focus 帧必须同时进入收集集合；本次修过“导出 frame 94、但未加入 keep”的检查脚本错误。
- 改画幅/时长时同步帧数、尾音、检查帧、SRT、主素材可用区间和工程包，不能只修改输出名或容器时长。
- 打包冻结之后再改脚本，要同步更新包中该文件、重提取并检查；重开工程要选真的含新效果的帧，而非只选实体字已经退出的尾帧。本片三维检查补选第 37 帧。
- 工程包保留原源、参考/alpha、字幕、分轨、调色参数/LUT、三维场景和脚本，省去可从源重建的工作 JPEG。字体版权与目标环境说明，不能分发系统字体或把工程依赖只留在外部生成目录。
- 可移植脚本的读取参数必须真影响渲染；本片部分字形时码在 Python 中，cue JSON/SRT 为记录/字幕交付，不假称修改 cue JSON 会自动改全部动效。
- 保存听检限制、识别边界与用户评价状态。技术验证数值、层数和作品时长都不是高质量/高热度的保证。
