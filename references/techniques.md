# 音乐剪辑技术选择表

先写每镜主体、动作、情绪和音乐事件，再选手段。高燃依赖行为与反差，不靠全片闪白、震屏或同一模板。

| 需求 | 可用实现 | 必查 |
|---|---|---|
| 高潮动作落点 | 变速曲线、方向匹配、景别跳切、短局部冲击 | 源范围、峰值发生帧、减速模糊/光流变形；不改变用户音乐速度 |
| 弱拍与内部状态 | 游标、按键、通知、条目打印、音量/排名 | 内容与内部结构可识别，不把内部变化全算整画面切镜 |
| 海报卡点 | 生成图分层、透视相机左右运动、前景遮挡、轻推近 | 视差不同、alpha清洁、文字可读、边界无露空 |
| 下一场景预显 | 先人物后环境、先环境后人物、门窗屏幕内预览 | 身份连续、背景干净、同目标时刻、归位完整 |
| 分片转场 | 天空/建筑/人物/道具mask，XYZ错时入场/翻折 | 互补所有权、同UV、软边无缝、端点恢复；不重复主体 |
| 遮挡切换 | 近景车/手/门掠过藏切点，方向承接 | 遮挡时机与轨迹，前景唯一 |
| 实景歌词/AR | 独立平面H，必要时PnP/相机解算，前景matte | 有效区间、漂移、手指遮挡；残差不等于视觉通过 |
| 印刷/极繁字体 | 字形像素切分、图底互换、字母重组、纸带、字面隧道 | 字形/镂空/阅读窗口；几何不假冒纸纹 |
| 压力/重量/折射 | 实体文字挤压、厚片/倒角/玻璃/布光，局部Cycles | 侧壁、接触影、暗部、噪点；不强制全片CGI |
| 叙事道具 | 门框/板/后景，杯沿/水/鱼，画框/画内，衣肢分组 | 铰链、遮挡、接触、动作因果；静脸替换非人物动画 |
| 静帧电影感 | 独立画面、静止与缓推/拉远/横移交替，局部雨/蒸汽/窗光 | 材质一致，避免周期漂移；真实表演与静帧合成区分 |
| 3D群舞/解构 | 骨架动作短句、厚片、形态键后骨骼变形、错拍 | 脚部支承、停舞反差、群体相位、轮廓；非动捕如实记录 |
| 梦核空间 | 长焦横移、广角穿行、草叶风动、层雾与焦点变化 | 尺度、密度边界、根部固定、景深与时间稳定性 |
| 音画因果 | 音符驱动琴键/物件、低频冲击、中高频局部变化 | 原曲、触发顺序与情绪；峰值不自动等于鼓点 |

连续短段验证机位与材质。纸片适合印刷，体积适合重量，干净实拍适合清楚动作；可按主题组合，颜色、字幕与声音连接段落，不以技术数量证明丰富。

## 实证修正

- 中央纸带/光环/大字挡主体：改深度、规模、时间或移除，不靠曝光解决。
- 生成主体和原背景都有角色：重做干净背景与互补matte，不加描边掩盖。
- 字句/切镜错0.3–0.5秒：统一源歌/输出时间换算，完整句后再关键词；行为词唱到时动作发生。
- 生图改变实拍材质：保真仅取辅助alpha；风格化以完整生成图同步背景。
- 同图重复副歌、无理由摆动：先设计段落后果和机位方向；需要动作则补素材，不机械加帧。
- 只有字幕动：运动检查排除字幕区域，检查真实主体/道具。
- 单帧Cycles被称全片质量：记录实际引擎、fps、采样和时域稳定性。
