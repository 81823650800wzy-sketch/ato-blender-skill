# 自主导演判断与混合制作

先读当前请求和素材，再决定风格。用户指定优先；只给歌曲和素材或说“你判断”时直接做判断，不要求用户选择软件、技法或重新填写风格问卷。当前用户给的七条参考优先于旧项目；读 [seven-reference-study.md](seven-reference-study.md)。参考是语言库，不是每条片必须复刻的模板。

## 风格由内容决定

| 素材/任务证据 | 主导剪辑 | 时间与信息组织 | 技术重点 |
|---|---|---|---|
| 有人物目标、对白、因果、反转、前后状态 | 叙事剪辑 | 原因→行为→反应/后果；保护表演与对白完整，反应镜头和停顿有作用 | 先纯剪辑和声桥，必要的隐形修补/特效单独做 |
| 日常、旅行、饮食、朋友、手持视角 | vlog | 地点/动作/触感建立经历；动作或前景连接空间；段落有呼吸 | 实拍主体＋少量情境字/状态，二维抠像与局部跟踪 |
| 不同场面围绕人物、动作、题材，音乐是主轴 | 音乐混剪 | 情绪弧线、动作峰值、方向/形状/视线承接；局部高潮加密 | 净切、变速、构图匹配；少数独立视觉段落 |
| 明确主视觉、产品、宣传或名场面定格 | 海报/设计混剪 | 原镜动作→姿态落点→视觉重构→清晰保持→回到运动 | 先完整美术与排版，再二维/2.5D；确需体积才建模 |
| 歌词意象/故事为主体，素材是插画或生成图片 | 叙事/概念MV | 语义转成可见变化，物件状态贯穿；副歌可以重复母题但有发展 | 图层角色与动作，必要体积镜头；避免整图摇摆代替动画 |

允许“对白叙事开场→音乐混剪→海报高潮→安静结束”，按段落改变主导方式；每段保留人物、色彩、文字家族或运动母题的连续性。不要根据单个风格词给全片贴同一种特效。

先写一句“观众应该经历什么”，再写段落弧线与素材能力。先做净剪骨架，检查没有装饰时人物关系、动作与音乐是否成立。若不成立，优先换镜头/顺序/时长，不叠特效遮掩。

## 按镜头分配制作端

| 当前需求 | 默认执行端 | 升级到Blender的理由 |
|---|---|---|
| 硬切、J/L声桥、变速、调色、常规字幕、画幅 | 剪辑时间线/FFmpeg等二维后期 | 不因软件可用而升级 |
| 贴图、撕纸、涂鸦、UI内部状态、定格海报、画中画 | 二维合成；RGBA图层、mask、仿射/四角变换、可靠字体 | 图层存在可见透视运动、真实厚度或需要空间相机穿越 |
| 保持手/杯、切换背景；主体先入、环境后入 | 生图辅助精修＋动态抠像＋二维合成 | 镜头需要跨深度视差或三维遮挡关系，二维变换不能保持几何 |
| 简单平面字/屏幕四角替换 | 验证后的平面跟踪，二维corner pin足够时直接用 | 平面交互复杂、相机移动引起明显视差、需要三维灯光/阴影 |
| 相机解算、真实场景AR、立体物件、空间文字、接触阴影 | Blender追踪/相机/代理几何/材质/遮挡 | 本身即三维任务；RGB底片保持相同时间和镜头模型 |
| 大幅绕拍、体积折纸、实体挤压、真实反射折射 | Blender | 需要真实几何及稳定体积关系，平面贴图不能冒充背面 |
| 最终声音、统一色彩、清晰字层、编码 | 二维收尾/音频混合 | 三维镜头以有版本的中间层接入，不重复重渲整片 |

Blender是实景合成和运动追踪的优先候选，但并非所有追踪都必须三维解算。平面单应可靠时保留简单方案；单应无法解释多深度运动时不可硬贴。

每个需加工镜头在镜头表记录：目的、视觉锚点、源范围、主事件、前后镜头关系、执行端和选择理由、图层/深度、声音职责、文字阅读区、完成检查。普通硬切无需填写无关的追踪字段。不要用固定二维/三维占比、镜头数或效果数量凑指标。

## 时间线与交接

- 输出帧率和项目范围在开工统一；变帧率源保存原PTS并生成稳定工作副本。源时间→剪辑时间→输出帧只有一份映射；嵌套合成记录入点，不凭平均帧率寻址变帧率原片。
- 二维与Blender共享帧范围、像素尺寸、色彩声明、alpha模式。透明中间层可用RGBA PNG序列或实际支持alpha的编码，不把普通H.264当透明片。区分straight/premultiplied，检查黑/白底边缘。
- 平面图层单独保留；Blender只生成该镜头所需透明层/深度或完整镜头，底片、字层、音轨仍可调整。场景文字与HUD的色彩管理可不同，但最终统一显示变换，防止双重转换。
- 短段验证选“最困难且代表真实方向”的连续段，覆盖入场、交互、保持、退出与声音。通过后自行扩展全片；失败先修素材/机制。不要以一个简单样片通过证明所有镜头可行。

## 选择文字政策

歌词MV以完整词句为默认；用户指定无歌词则遵守。vlog以环境信息/情境短句为主，音乐混剪按画面需求选关键词或无字幕；叙事片优先对白字幕，海报大字承担身份与视觉结构。不要把所有vlog和对白片都变成满屏歌词MV，也不要用关键词版冒称完整歌词版。所需文本可从用户提供音视频转写并校对；自动识别存在不确定就记录，不因歌声识别差擅自改词。

## 结束判据

先按 [edit-language.md](edit-language.md) 自审叙事、视线、信息量、排版与调色，再按 [sound-design.md](sound-design.md) 审声音，最后执行 [delivery.md](delivery.md) 的编码和工程检查。美术失败即便解码通过也要修正。只在缺少不可替代输入时追问；普通制作选择由agent完成。
