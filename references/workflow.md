# 从参考到成片

## 准备与拆解

定位原工程及已交付版本，探测尺寸、帧率、可变帧率、音频、旋转和编码。保留原片，工作序列统一时间基准。建议目录 sources、assets/generated、assets/mattes、tracking、scenes、renders、reviews。清单记录源片入点、fps、生成提示词、mask 来源和镜头时段。

参考接触表只用于定位，随后查看连续帧：对象持续性、下一镜头预显位置、遮挡主体、平面方向、尺度与 UI 延续。教程主要在字幕时读取关键字幕。描述原理为画面推断，不声称取得原工程。可观察的语言包括：持续 UI、手部桥接背景、建筑遮挡月亮、门窗内预显、近景遮挡藏切点、形状方向衔接。按用户参考选择，不默认全用。

## 音乐与镜头表

歌词关键词与节拍关联到可见动作。记录音乐/视频时间转换，将转场拆成预显、依次入镜、归位、保持。瞬态与 ASR 只提供候选，未经听检不能称精确卡点。镜头表包含源/目标、语义层、持续前景、入点、片块顺序和动作、完整归位时刻、歌词、追踪来源、审查帧。先验证短片再扩展全片。

## Blender 合成

真实视频作背景，代理几何只提供投影、遮挡与光照。片块保留原 UV，允许 XYZ 位移、倾角、尺度和延迟，结束归位到同一重建平面。真实空间转场和屏幕平面转场要明确区别。

移动手机的控件随其姿态，沿边框左右分组，留出手部间距并检查投影出框。依据实际遮挡图安排层次；常见顺序为背景、分片、局部背景模糊、空间 UI、持续手/手机、必要纸边、字幕。控件在部分手指前时拆前景层，不全局翻转顺序。

实拍景深已经烘焙，不把远背板再次全局虚化。CGI 与实拍分别管理焦点；二维模糊不等于完整三维景深重建。需要局部模糊时用独立不透明 UI mask 渲染层，在 mask 内模糊背景后叠清晰 UI，不假设所有渲染器有 IndexOB。

Blender 4.5 Eevee 可测试 BLENDED 平滑透明；DITHERED 低采样噪点需检查。ShaderNodeTexImage 序列属性在 image_user；CompositorNodeImage 的 frame_duration/frame_start/frame_offset/use_auto_refresh/use_cyclic 在节点本身。字幕放最终清晰层，检查中文和符号缺字。

统一曝光、饱和度、网点/颗粒和暗部在最后进行。青色数据、品红情绪、酸黄强调、深蓝底仅为可选色板。滤镜不能掩盖追踪漂移与边缘毛刺。

## 镜头设计扩展

在音乐镜头表中加入增强类型、挂载平面、内部交互、追踪有效区间、无控件原因、切镜关系和主题色彩目标。按 [visual-language.md](visual-language.md) 选择同主体换背景、同背景换主体、场景先出等关系，并按 [style-and-color.md](style-and-color.md) 设计生成素材和最终曲线。片块归位规则保持不变；控件数量不能代替内容、状态与空间行为的丰富度。
