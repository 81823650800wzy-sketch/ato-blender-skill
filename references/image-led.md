# 生图、抠图与图片驱动3D

| 需求 | 生图负责 | 合成负责 |
|---|---|---|
| 保真实拍前景 | 保留身份/姿态的透明前景或辅助mask，不改变衣着/手指 | 配准alpha后取原视频RGB；连续帧传播并检查，失配重新锚定 |
| 风格化海报 | 基于原图重建清晰细节、完整构图、色彩、材质和排版 | 从生成图提取主体/排印/前景，保留单独干净背景 |
| 动画图层 | 同一构图的干净背景、透明主体/道具、前景遮挡层与状态变体 | 统一画布/坐标，各物件独立动作，不把整图推拉当角色动画 |
| 抠图后露洞 | 补全原场景被主体挡住的区域 | 匹配透视、色温、噪声与曝光，背景不残留重复人物 |
| 撕纸/纤维 | 真实印刷、纸纤维、卷边和alpha | 沿语义mask对齐，几何提供XYZ与厚度，不用锯齿网格假冒纤维 |

遵循imagegen skill：先看原图，明确参考与编辑目标；实际调用模型编辑外观，不只写提示词。生成后复制进工程，保存提示词、来源和实际尺寸。默认内置工具，失败报告限制，不默转收费API，也不改写同一请求绕过审核。

## 精细度与一致性

先生成可独立成立的完整海报，再按其角色尺度、排版与光色准备图层。精细主体/大字宜独立全画幅生成，图集只用于小道具；多格图集分割后像素会不足。按每个资产实际尺寸判断，不以“高清”提示词替代测量。

提示写明原角色/物件结构、必要裁切补全、身份与姿态、风格化程度、主体留白、文字原文、光线方向、调色、细节和投影用途。去背景要真正透明alpha，不接受白底/棋盘格烘焙。精确统计、歌词、小字可靠排字；生图排印可作艺术主体，仍须核查拼写。

逐层比对姿态、尺度与构图。关键特征用相似/仿射或单应配准，不以强烈非刚性扭曲掩盖身份、肢体或材质漂移。layers.json记录裁剪框、原画布、UV中心、对齐矩阵，避免重新猜位置。

## alpha与动画

### 通用生图轮廓参考法

这套方法可用于所有抠图相关任务：人物/动物/道具去背景、天空与建筑分层、前景遮挡、孔洞保留、轮廓描边、转场分片和单帧重构选区。需要新建或修正复杂遮罩时优先考虑；已有可靠 alpha 或简单可准确确定的轮廓可以直接复用，不为统一方法反复生图。

查看实际源帧后，以原帧为编辑目标，让内置生图提供透明主体、黑白遮罩或纯色语义分区参考。提示锁定画幅、相机、主体身份/姿态、物件位置、轮廓与孔洞；纯色分区只用于分配语义，不从生成的阴影/纹理推断 alpha。保存原帧、完整提示词、生成参考和尺寸，先配准，再借原图边缘、颜色、GrabCut 或手工修正得到最终遮罩。参考的生成 RGB 不替换保真实拍 RGB，生成的轮廓漂移也不能直接当作正确抠像。

分别检查发丝软边、透明/半透明材质、指缝、车轮孔洞、细杆和运动模糊；纯色硬分区不能代替这些显示 alpha。多层遮罩按语义优先级建立互补所有权，显示羽化另处理。动态段用检查过的锚帧传播，遮挡或姿态改变时重新锚定；不把一个静态模型遮罩盖住整段，也不逐帧独立生图造成轮廓闪烁。实际例子及分块检查见 [单帧重构与动态手绘](frame-reconstruction-and-ink.md)。

检查发丝、指缝、衣袖、翅膀、车轮孔洞、建筑尖端。alpha微雾会污染bbox；按画面清理近透明噪声，保留软边与运动模糊，不一律二值化。连通组件、GrabCut与颜色阈值仅辅助资产提取，不代替精修和视觉检查。

静态海报可用定格alpha。保真视频在变化大姿态生成锚帧mask，用光流/追踪短程传播并检查前后向误差；遮挡改变或置信失败就重新锚定。最终RGB取当前原片帧。生成姿态改变时不能硬贴到运动原片；可明确转入风格化定格段。

动态物件须从背景移除，同时出现两份门/杯/钟/人物/标题属于分层失败。主体/环境使用互补所有权和同一时刻，归位恢复共同目标。不能为丢失的真实内容编造运动。

## 3D从生成图出发

将已通过检查的生成构图转成远背景、中景主体、排印、近景遮挡。可靠UV、干净alpha；厚度只加在纸页、排印或实际侧壁。透视相机横移/左右绕拍产生层间视差，近层幅度大于远层，不让全部图层同样平移。

完整运动范围检查露空、双影、不可读文字与悬浮裁切边。人物截断边藏在画幅/前景后；大幅横移会露出单图没有的侧面，应限制动作或准备新视角，不把纸片绕背当体积角色。

已烘焙光影的生成图尽量用发光/无额外照明材质保持。真实纸张阴影可用受控代理层；深度估计仅使用已有本地模型且检查可靠，不以图像亮度当深度。造型、照明或视角确需重建再使用真实3D。
