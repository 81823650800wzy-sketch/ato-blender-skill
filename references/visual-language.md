# 场景增强、切镜与音乐动作

## 从参考提取行为

查看原片连续帧，记录控件内部动作、持续身份、遮挡、空间方向和音乐触发点。接触表只用于定位，不能代替观看转场过程。新增网络参考记录作者、页面和可访问程度；只读到标题/字幕时，不宣称已分析画面。参考线索见 [reference-study.md](reference-study.md)。用户提供的作品优先于网络标签，不把 ATO 当成统一官方模板。

以下方式构成可扩展的创作手段库。选择能表达当前内容的方式，并在全片中形成有理由的变化；不要求用齐，不按列表逐项打卡，不因出现某个主体就自动套用对应效果。可用构图、动作匹配、信息揭示和节奏变化丰富剪辑，也可采用参考中未列出的适配方案；简单切镜、母题复现和留白仍可成立。

## 熟悉程序和空间界面

多数控件借鉴用户熟悉的程序：导航栏保留当前页与层级，播放器保留封面/播放状态/进度，通知保留来源/内容，亮度或音量滑条保留轨道与滑块。根据歌词决定是否需要点按、状态切换、游标移动、进度变化、展开收起；装饰矩形与标题不能替代内部功能。选取相关组件，不要求把整个程序全部复制。

优先裁切已有真实截图的完整信息区域，保留字体、数值、留白、图标和宽高比，避免裁掉标签或重绘成近似字。没有合适原图再设计或生成视觉资产。实际数据用截图或可靠排字；生图不能承担准确数字与歌词拼写。

AR/VR 参考可用于透明层、空间窗口、视线焦点、局部磨砂和深度排列。按实拍挂载面建立透视，适配遮挡和焦距，磨砂只作用于面板下面的背景。不要让纸边、辉光或贴纸覆盖控件内容。手机外可左右分组、错开高度和深度；其他场景按桌面、墙面、建筑或物体边界重新布局，不强制沿手机布局。

每镜头记录增强类型、歌词含义、挂载物/平面、局部坐标、内容来源、前后遮挡、入场/内部动作/离场、有效区间和无控件原因。跨镜头可保留组件身份，但必须重建新镜头的姿态与布局。

## 构图与信息分布

先选视觉中心，再从主体、场景文字、控件、气泡和下一主体预告中选取所需元素，为实际选用的元素分配空间与出现时段；不必全部加入。利用实拍空位和参考面的不同边缘展开，不把全部信息堆到一个角落，也不机械填满四角。面部、关键动作和行进方向优先保留；用完整运动区间检查碰撞，静帧留白不能证明运动中不拥挤。

若选用中文语境的手绘气泡，内容多用简短中文调侃，来自当前动作或情景，不能脱离主体硬贴笑话。气泡可用云形、椭圆或强调框，尾线/思考点指向其所属主体；描画进入、文字阅读和主体运动分别安排时段。手写中文需检查缺字、笔画厚度与最终观看尺寸，不能用英文模板替代用户要求的中文表达。

## 完整歌词与场景融合

先按 [导演判断](directing-and-routing.md) 决定文字政策；以下完整覆盖规则适用于歌词MV或用户明确要完整歌词的任务，不自动套到vlog、叙事或纯混剪。完整覆盖包括重复句与跨切镜持续句。用户提供的歌词或音视频可用于转写、校对与时间定位；未提供的受保护完整歌词不得靠外部检索补全。识别不可靠时记录具体未定字句，继续独立工作，必要时请用户确认文本；不把关键词版声称为完整歌词版。

把发声区间、逐句显示、关键词强调和原创文案分别记录。ASR 可辅助对齐合法可用的文本，不能绕过文本来源限制，也不能用识别结果直接定稿。关键词用于强调，原创文案用于补充情景，二者都不填补漏掉的歌词行。

按场景选择表现，而非每句套一个平面字幕模板：

- 墙体、立面、地面或桌面：沿同一参考面的局部坐标排字或滚动，法线、消失方向和运动都与该面一致。磨损/粉笔纹理保留足够笔画，别把字投到相邻人物、桌沿外或另一深度的区域。
- 组件延伸：歌词可在组件下方或沿其边缘展开，保持适当的空间关系与阅读区，不挤占组件功能内容。
- 主体环绕：沿语义轮廓或弧线排字，适配主体运动；避免字母逐帧抖动、过度旋转或被主体长期吞没。
- 天空滑翔：文字和笔迹可模仿鸟翼或行进轨迹，结合相机运动与建筑/树木遮挡。需要正片叠底时使用真实 Multiply 合成及合适的深色墨迹，不能用降低不透明度冒充；纯白在 Multiply 中不会形成可见白字，白色字需选择适配的合成方式并如实记录。

文字必须在实际输出中足够大、清楚且有阅读时间；透视压缩、玻璃反射或前景遮挡不能导致整句不可辨。确需遮住部分场景字时，安排可读的揭示/保持时段，或用清楚的辅助字幕保证逐句覆盖。跨切镜保持句子连续，不因抠图入境或归位而漏显歌词；辅助层也应让开脸部与动作。

## 无控件也是镜头设计

同时通过空间可靠性与叙事适合度才显示控件。预先按输出分辨率、物体大小和模糊程度确定可接受误差，检查分布、残差、遮挡及姿态跳变；不能为凑效果数量放宽门槛。剧烈晃动导致追踪超限、挂载面离开画面或音乐需要平静时，使用无控件布局。有效的快速运动可保留增强，不能仅凭“晃动”判失败。

短暂丢失只有在插值/重追踪经过检查后才能桥接。否则在有效边界前收起；突发失败及时撤掉增强，不冻结上一次姿态。面板、背景模糊 mask、尾线、投影、辉光和相关遮挡层同步退出，避免留下磨砂幽灵。平静段不要用密集文字替代被撤掉的面板。

## 超越控件

- 场景歌词：按上述完整覆盖规则逐句显示，强调部分参与墙面、桌面、主体边缘或虚拟空间的透视、景深与遮挡；先保证可读，再做变形。
- 裁切视频：游戏/旅行内容成为窗、画框或空间屏幕；独立处理帧率、入点、长宽比、四角透视及手部遮挡。
- 模型：承接歌词意象或空间互动，匹配尺度、光向、接触阴影、材质与焦点。不要用粗糙建模代替应生图提供的纸边细节。
- 图片与实拍前景：图像可从手机展开成空间画面，手部可持续跨背景；抠像边缘、指缝、玻璃和运动模糊需逐段检查。

按情节选择一种主行为与必要辅助行为，丰富度来自变化和关联，不来自一帧堆满所有类型。

## 切镜关系

先选择叙事关系，再选择转场外观；用户要求下一画面分片入镜时保持这一约束，采用分片时沿明显轮廓组织，详见 [contours.md](contours.md)。ATO、ODD、粉笔与撕纸可混用，但按主体和音乐挑选，不要求每首歌全部出现：

| 关系 | 实现重点 | 检查 |
| --- | --- | --- |
| 同一主体，背景切换 | 保留手/手机等前景，下一背景按天空/建筑等轮廓入镜拼合 | 主体只出现一次，背景时间统一，新的光色有合理过渡 |
| 同一背景，主体变换 | 稳定背景，下一主体以轮廓片块进入；补齐原主体露出的区域 | 清理旧主体残影，保持脚/桌接触和影子一致 |
| 先场景后主体 | 下一场景的环境片先拼合，主体在后续重音/歌词出现 | 空场有叙事用途，主体出现前无残影 |
| 先主体后场景 | 下一主体先入镜，再由环境片补成完整下一画面 | 明确过渡期空间，最终回到共同目标坐标 |
| 门洞/屏幕预览 | 下一景先在真实孔洞或窗口内可见，再分层展开 | 孔洞的遮挡、透视和最终画幅一致 |
| 近景遮挡桥接 | 前景物经过画面时携入下一镜头片块 | 遮挡方向匹配，不用遮挡掩盖最终接缝 |
| 形状/动作匹配 | 相似轮廓、运动方向或屏幕区域承接下一素材 | 先对齐视觉锚点，再拼接剩余目标画面 |

使用分片时，完整目标帧中的主体须参与同一时间/坐标恢复；主体延后出现时，先准备经检查的干净背景，不能只留下洞。持续镜头内的主体/背景变化不必人为加切镜。用户明确要求分片归位时不能退回普通擦除；其他机制按其叙事关系完成清晰的镜头接替，不强制全部撕纸化。

## ODD 式错落抠图入境

需要这一拼贴语言时，从参考连续片段判断其实际顺序，不以“ODD”标签代替分析，也不强制每个切镜使用抠图预告。可以让下一主体先作为轮廓抠图预告，环境稍后接替；也可以环境先入、主体在重音出现，描边随后揭示身份，气泡或控件最后补充信息。选用多层入境时，各层错开进入和退出，避免每个抠图同时弹出、统一大小或固定居中。

预告占用当前镜头空位，保留当前主体的视觉中心。预告结束、正式入境与目标归位应有连续的视觉关系；时段重叠时避免无意出现两份同一主体。使用与正式镜头衔接的运动片段，不默认冻结一帧反复展示；所有抠图仍检查实际轮廓、前后景遮挡和源时间。

## 节奏层次

先听音乐与词义，区分起句、重音、鼓点、停顿、情绪升降。强拍可触发切镜或主体出现，弱拍可触发滑块、图标、文字等内部动作；平静处保留镜头呼吸。采用预告—入场—交互—停留—退出，允许不同组件错拍，不把每次动作都压在同一帧。快段增加事件密度，慢段减少；不用固定控件数、固定转场长度或统一弹跳曲线。检查连续观看的节奏，并逐帧核对关键遮挡与归位。

快节奏 VLOG 也须留出辨认主体和阅读歌词的保持段。稍微放缓优先改善短促切镜、入境层间隔和阅读窗口，同时保留动作峰值的重音落点；描边可在轻拍描出、抠图在重音落位，而非每拍都整画面硬切。
